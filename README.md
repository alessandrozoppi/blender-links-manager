# Blender Links Manager

A simple Blender addon to easily manage linked resources. Adds a UI panel to quickly see, reload, open and find linked libraries.

## Setup

- Download .zip file from [latest release](https://github.com/sintesilabs/blender-links-manager/releases)
- In Blender, go to Preferences > Add-ons
- Click on the top-right dropdown > Install from Disk...
- Select the downloaded .zip file

A new "Links Manager" panel should appear in the 3D view sidebar (shortcut: N)
